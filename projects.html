Capstone Project

Online Exam App with Item Analysis

An Online Exam App with Item Analysis developed as a capstone project using Flutter, Dart, and Firebase. The application supports both Web and Android (APK), allowing instructors to create and manage examinations, monitor student performance, and generate item analysis reports for evaluating assessment quality.

This system was developed exclusively for academic use within our client institution. Due to project restrictions, the source code is not publicly available.

Technologies Used

Flutter Dart Firebase

Key Features

  • Cross-Platform (Web & Android APK)
  • User Authentication
  • Student and Instructor Accounts
  • Create and Manage Online Examinations
  • Automatic Scoring
  • Item Analysis Reports
  • Firebase Database Integration
  • Screenshot Prevention During Examinations
  • Tab Switching Detection with Warning System
